# 两个入口：国内版与国际版

`searchByBing(query, { bingEnterance })` 的两个取值。本文回答：检索质量谁更好、
该默认哪个。

## 入口选择

```ts
// 中国大陆与港澳台 → cn，其余 → international
const CN_TIMEZONES = new Set([
    'Asia/Shanghai',
    'Asia/Chongqing',
    'Asia/Harbin',
    'Asia/Urumqi',
    'Asia/Kashgar',
    'PRC',
    'Asia/Hong_Kong',
    'Asia/Macau',
    'Asia/Taipei',
])

function resolveEntrance(explicit, timeZone) {
    if (explicit === 'cn' || explicit === 'international') return explicit
    return CN_TIMEZONES.has(timeZone) ? 'cn' : 'international'
}
```

**显式传 `bingEnterance` 永远优先。** 时区推测只是默认值。

> 但实际上没什么意义，因为绑定的是 cn.bing.com 这个域名。

## 该用哪个：判据

依据是一次 A/B（20 题 × 5 领域 × 2 入口）。
分领域看一手源密度（Bing 返回的池子里官方站/原典/原文全文的占比）：

| 领域     | 国内版  | 国际版  | 差         |
| -------- | ------- | ------- | ---------- |
| 编程     | 26%     | **33%** | 国际 +7pp  |
| 外国文学 | 4%      | **10%** | 国际 +6pp  |
| 非遗     | **14%** | 10%     | 国内 +5pp  |
| 数学     | **29%** | 17%     | 国内 +12pp |
| 中国史   | 29%     | 29%     | 打平       |

总体四项纯搜索指标（一手源密度、关键页递送速度、结果覆盖率、命中名次）三项打平，
唯一分开的是下面这张表：

| 领域            | 该用哪个   | 机制                                                                                                    |
| --------------- | ---------- | ------------------------------------------------------------------------------------------------------- |
| 编程 / 技术文档 | **国际版** | rfc-editor / doc.rust-lang / sqlite.org / docs.python.org 在国际版排得更前；国内版常被 CSDN、掘金先占位 |
| 外国文学        | **国际版** | 差距最大。Standard Ebooks / Gutenberg / Wikisource 只在国际版池子里出现                                 |
| 中国史 / 古籍   | **国内版** | 识典古籍、维基文库、24shi.wiki 的位次更稳（但两边都能进）                                               |
| 数学 / 形式化   | **国内版** | 中文数学术语的召回更准；国际版更容易掉进 HandWiki 这类百科                                              |
| 非遗 / 地方文化 | 打平       | 两边都进得了 ihchina.cn                                                                                 |

**判据不是「题面有没有英文」，也不是「中文主题用国内版」。**
前者在回放里只有 12 对 7 错；后者与数据相反——中国史是国际版全胜的一段。
真正的判据是**你要的东西在哪一类信源里**：

> **要英文原典（RFC / 官方文档 / 英文原作全文）→ 国际版。**
> **要中文术语的学术解释（数学概念、古籍原文）→ 国内版。**

### 一个必须承认的天花板：文学题都不行

文学类的一手率国内 8% / 国际 18%，但**两边池子里的一手源都只有 4% / 10%**。

> **文学题的原作全文在两个入口里都不足 10%，国际版只是「没那么糟」。**

所以文学类答案大量依赖二手解读——**不是模型不用原文，是 Bing 根本不把原文排上来**。
换入口解决不了，要做就得加站点定向能力。
